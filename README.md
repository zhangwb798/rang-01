# 靶场 / RANGE 01

本地第一人称练枪原型。双击 `index.html` 即可使用，Three.js 已保存在 vendor 目录，无需联网、安装依赖或构建。

推荐使用桌面版 Edge / Chrome，开启硬件加速。点击「进入靶场」后浏览器锁定鼠标，按 Esc 暂停并释放鼠标。

## 操作

- WASD：移动；Shift：奔跑；空格：跳跃
- 鼠标：转动视角；左键：射击（按住连射）；右键：瞄准
- R：换弹，30 发弹匣，备用弹药无限
- T：补满所有玻璃瓶；Esc：暂停

自由练习不限制时间；限时挑战为 60 秒，仅在训练进行时计时，暂停时停止。击碎全部 36 个瓶子后自动补充。命中率按击碎瓶子数 / 发射子弹数计算。最佳挑战成绩使用浏览器 localStorage 保存，不同浏览器分别记录。

浏览器不支持鼠标锁定时自动进入兼容模式：按住右键拖动视角，方向键微调，左键射击。

如浏览器限制本地文件的鼠标锁定，可在此目录运行 `node server.cjs`，访问 http://localhost:4173 。

当前包含三组分层瓶架、玻璃碎片、弹着点、后坐力、移动散布、瞄准、换弹、合成音效和训练统计。场景、枪械、贴图均由代码生成；不是 CS 官方作品。

第三方依赖：Three.js 0.160.1，MIT 许可，见 vendor/LICENSE.txt。
